## PLOTLY-REQ-001: Plotly as default plotting library

**Type:** Ubiquitous
**Summary:** When Python code produces a plot without explicitly importing a plotting library, the system SHALL use Plotly.

The Pyodide setup code SHALL import `plotly.express` and `plotly.graph_objects` by default, and SHALL capture Plotly figures generated by `pio.show()` or `fig.show()` calls. Captured figures SHALL be rendered as interactive HTML in the code output panel.

**Location:** `src/canvas_chat/static/js/pyodide-runner.js` — setup code preamble

---

## PLOTLY-REQ-002: Plotly HTML output rendering

**Type:** Ubiquitous
**Summary:** Plotly figures SHALL be rendered as interactive HTML in the code output panel.

When a Plotly figure is captured, the system SHALL:

1. Export the figure as HTML via `fig.to_html(include_plotlyjs='cdn', full_html=False)`
2. Store the HTML in `_figures` as `{ type: 'plotly', html: '...' }`
3. Render the HTML in the code output panel using a sandboxed approach

**Location:** `src/canvas_chat/static/js/pyodide-runner.js` — figure capture; `src/canvas_chat/static/js/plugins/code.js` — output rendering

---

## PLOTLY-REQ-003: Matplotlib backward compatibility

**Type:** Exception-driven
**Summary:** If the user explicitly imports matplotlib, the system SHALL still capture matplotlib figures as PNG images.

The Pyodide setup code SHALL retain the existing matplotlib Agg backend capture logic. Both Plotly and matplotlib capture can coexist. If a code cell produces both Plotly and matplotlib figures, both are included in the output.

**Location:** `src/canvas_chat/static/js/pyodide-runner.js` — matplotlib fallback setup

---

## PLOTLY-REQ-004: Plotly package auto-installation

**Type:** Event-driven
**Summary:** When Plotly is imported by user code or the setup preamble, Pyodide SHALL auto-install the `plotly` package.

`plotly` SHALL be added to the auto-install package list in `pyodide-runner.js` alongside `pandas`, `numpy`, `scipy`, `matplotlib`, and `seaborn`.

**Location:** `src/canvas_chat/static/js/pyodide-runner.js` — `autoInstallPackages` / package list

---

## PLOTLY-REQ-005: Plotly default in agent code generation

**Type:** State-driven
**Summary:** When the agent generates code that creates a plot, it SHALL use Plotly by default.

The agent's system prompt SHALL instruct it to prefer `plotly.express` or `plotly.graph_objects` for any plotting tasks. Matplotlib SHALL only be used when the user explicitly requests it or when Plotly is unavailable.

**Location:** `src/canvas_chat/app.py` — agent system prompt
