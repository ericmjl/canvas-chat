# Presentations

Single-file HTML presentations for Canvas Chat, viewable in any browser.

## Canvas Chat Overview

**[View the Canvas Chat Overview presentation](canvas-chat-overview.html)** — Product overview and workflow demos.

When you follow the link above, the deck opens in the same tab. Use your browser back button to return to the docs. You can also open the [HTML file](canvas-chat-overview.html) in a new tab (right‑click → Open link in new tab) or download it and open locally.

- **Slide navigation:** Space / → / k = next; Shift+Space / ← / j = previous; **Escape** = slide grid
- **Contents:** Title, “Conversations as a graph” demo, core workflows (Chat & Reply, Highlight & Branch, Multi-Select, Auto-Layout, Navigate, Export/Import), architecture, tech stack, thank you

The deck uses the same single-file pattern as the [html-presentations](https://github.com/ericmjl/skills/tree/main/skills/html-presentations) skill (vanilla HTML/CSS/JS, keyboard nav, URL hash persistence). Several slides include **looping animated demos**: simulated cursor, typing, node layout, and semantic zoom.
