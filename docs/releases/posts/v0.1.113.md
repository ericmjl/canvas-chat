# Version v0.1.113

This release includes several dependency updates to improve the CI environment and tooling. Key updates include upgrading the Node.js setup action to version 7, updating the Pixi setup action to 0.11.0, and bumping various indirect dependencies to their latest versions.

## New Features

- Upgrade GitHub Action for Node.js setup from version 6 to 7, bringing improvements and new features to the CI workflow (bc91a9) (dependabot[bot])
- Update GitHub Action for Pixi setup from 0.10.0 to 0.11.0, enhancing the CI setup for Pixi projects (7cb9cc) (dependabot[bot])

## Bug Fixes

- Bump toml package from 4.1.1 to 4.3.0 to incorporate bug fixes and improvements in TOML parsing (cccdf2) (dependabot[bot])
- Update brace-expansion package from 1.1.12 to 1.1.21 to address bugs and improve stability (c8cc19) (dependabot[bot])
