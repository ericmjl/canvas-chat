# Version v0.1.115

This release improves the validation logic for custom model identifiers, allowing new OpenRouter presets and suffixes to be accepted without errors. It ensures better compatibility with model IDs that include provider prefixes and special suffixes.

## New Features

- No new features added in this release.

## Bug Fixes

- Fixed custom-model validation to accept OpenRouter preset and suffix model IDs such as `openrouter/@preset/deepseek` and suffixes like `:free` or `:exacto`, while maintaining sanity checks on provider prefixes and formatting (75651a) (Cursor Agent)

## Deprecations

- No deprecations in this release.
