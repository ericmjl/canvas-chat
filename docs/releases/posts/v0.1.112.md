# Version v0.1.112

This release introduces dynamic discovery and filtering of Ollama image models, replacing the previous hardcoded options. It also adds end-to-end Cypress tests to ensure the Ollama image model dropdown behaves correctly, and fixes a markdownlint issue in the release notes documentation.

## New Features

- Implement dynamic Ollama image model discovery with capability filtering to show only image-capable models in the dropdown, improving flexibility and accuracy (f4cee6) (Eric Ma)
- Add Cypress end-to-end tests for the dynamic Ollama image model dropdown, including model population, placeholder display when Ollama is offline, and correct model ID submission (8ac4cc) (Eric Ma)

## Bug Fixes

- Escape `<think>` tag in release notes markdown to fix markdownlint no-inline-html errors that were blocking PRs (b9470d) (Eric Ma)

## Deprecations

- None
