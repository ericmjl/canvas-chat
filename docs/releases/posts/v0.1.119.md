# Version v0.1.119

This release focuses on improving how loopback origins are handled by normalizing them to `localhost`, ensuring consistent session and storage behavior across different loopback addresses. It also fixes an issue with running Cypress tests in Electron environments by removing a problematic environment variable.

## New Features

- Normalize loopback origins (`http://localhost`, `http://127.0.0.1`, `http://0.0.0.0`) to `localhost` to unify session and storage data, with a migration modal to assist users in exporting and continuing sessions under the new origin. This includes frontend, backend, E2E test updates, and documentation improvements. (552b5f) (Eric Ma)

## Bug Fixes

- Fix Cypress test runs in Electron-based hosts by removing the `ELECTRON_RUN_AS_NODE` environment variable from the Cypress process, preventing startup errors and enabling headless test execution. (95ac97) (Eric Ma)

## Deprecations

- None
